The July 17 target is a ladybug: a big red disc on an olive background, a dark half disc for the head at the top, and four small dark legs, two on each side. H_Bliertz draws it with the shadows of html and body only. Both elements get the same list of five shadows. `font:1%a` gives body a 0.16px font, so the same `62em` spread is 992px on html, the olive background, and 9.92px on body, the thin ring that cuts the legs off the disc.

Use **Wide view** to see html below the canvas and body above it, and **Teaching colors** to tell the shadows apart.

## The code, spaced out

```css
<style>
* {                                /* html, head, style and body */
  margin: 83% 70 -52;              /* html: 332 at the top (83% of 400), a 260 × 20 strip at (70, 332) */
  color: #212C;                    /* #221122 at 80%: the shadows' color */
  box-shadow:                      /* the same five shadows for html and body */
    0 -2in,                        /* 192px up: html's upper legs */
    0 -19ch,                       /* 152px up on html (1ch = 8px): its lower legs */
    0 3in #AF3737,                 /* 288px down: body's red disc */
    0 3in 0 62em #A8AF6A,          /* spread 992px on html: the background; 9.92px on body: the ring */
    0 188q 0 -53q;                 /* 177.64px down, 50.08px smaller: body's head */
  * {                              /* * *: head, style and body, not html */
    border-radius: 8in;            /* 768px: body is a circle */
    margin: -540 30 360;           /* body: 200 × 200 at (100, -208) */
    font: 1% a                     /* 1% of 16px: em is 0.16px on body */
```

## How it works

### 1. html: a strip below the canvas

There is no doctype: the page is in quirks mode. The style element is never closed, so everything after `<style>` is CSS. body is empty.

`*` matches html, head, the style element and body. head and style are not displayed. The nested rule changes body's margin, so `margin:83%70-52` only stays on html.

A margin in % is a share of the containing block's width, even for the top margin: 83% of 400 is 332. A number with no unit counts as px in quirks mode, so the sides are 70 and the bottom −52.

In quirks mode, html fills the window minus its margins: 400 − 140 = 260 wide, and 300 − 332 + 52 = 20 tall. getBoundingClientRect gives (70, 332), 260 × 20: html sits just below the canvas.

Nothing has a background: without the shadows, the canvas is white.

### 2. body: a circle above the canvas

The nested `*{…}` has no `&`, so it means `* *`: everything inside html. That is head, the style element and body, not html.

For body, it replaces the margin with `margin:-540 30 360`. In quirks mode, body fills html minus its margins: 260 − 60 = 200 wide, and 20 + 540 − 360 = 200 tall. Its top is 332 − 540 = −208. getBoundingClientRect gives (100, −208), 200 × 200: body sits above the canvas.

`border-radius:8in` is 768px, more than half of 200: body is a circle.

### 3. One shadow list, two elements

html and body get the same `box-shadow`. A shadow with no color takes the text color: `#212C`, a 4-digit hex color with alpha. It is #221122 at CC = 204/255, so 80% opacity. Over the olive, it shows as (61, 49, 48) in my render: the dark of the legs and the head. The target's dark is #3e3030, (62, 48, 48).

Each shadow is a copy of the element's box, moved by its offset and grown or shrunk by its spread. The first shadow of the list is painted on top. body is painted after html, so all of body's shadows are above html's.

### 4. html's shadows: the legs and the background

html's box is 260 × 20 at (70, 332). Its font is 16px Times.

- `0-2in`: 1in = 96px, so 192px up. The copy runs from y = 140 to 160, x = 70 to 330.
- `0-19ch`: 1ch is the width of the "0" in html's font, 8px. 19ch = 152px up: y = 180 to 200.
- `0 3in#AF3737`: 288px down, y = 620 to 640. That red copy is off the canvas.
- `0 3in 0 62em#A8AF6A`: the same offset, and a spread of 62em = 62 × 16 = 992px. The copy grows by 992px on each side: from (−922, −372) to (1322, 1632). It covers the whole canvas in olive, under the two bars.
- `0 188q 0-53q`: the spread is −53q = −50.08px. It shrinks the 20px tall box by 100.16px: nothing is left.

So html gives two dark bars, from x = 70 to 330, and the olive background.

### 5. font:1%a: 62em is 9.92px on body

The nested rule gives body `font:1%a`: a font size of 1% of html's 16px, so 0.16px. The `font` shorthand needs a family: `a` is one, a font that does not exist.

getComputedStyle reports 6px for body's font size. But body's computed box-shadow has a spread of 9.92px: em lengths use 0.16px, and 62em = 62 × 0.16 = 9.92px. Its ch is 3px, so `0-19ch` is only 57px on body.

### 6. body's shadows: the disc, the ring and the head

body's box is the 200px circle at (100, −208).

- `0-2in` and `0-19ch`: the copies go up to y = −400 and −265, off the canvas.
- `0 3in#AF3737`: 288px down. The copy is a red disc from y = 80 to 280, centered at (200, 180).
- `0 3in 0 62em#A8AF6A`: the same offset, and a spread of 9.92px. It is an olive disc of radius 109.92, under the red one: a 9.92px ring around it, from x = 90.08 to 309.92. It covers the middle of html's bars. What is left of them are the four legs: on the left, the upper leg reaches x = 91.91 to 97.62 along the ring, and the lower one x = 90.08 to 91.91. The right side is the mirror image.
- `0 188q 0-53q`: 1q is a quarter of a millimeter, so 188q = 47mm = 177.64px down. The spread −53q = −50.08px shrinks the circle to 99.84px. The copy is a disc at (150.08, 19.72), centered at (200, 69.64). It is the last shadow, so it is painted under the ring and the disc. They cut its bottom: the head.

## Golf notes

Below, a pixel counts as changed when one of its channels moves by more than 8.

- One shadow list does two jobs. The same `0 3in 0 62em#A8AF6A` is the background on html and the ring on body. `font:1%a` is what makes the difference. Without it (145 characters), body's spread is 992px too: body's olive copy covers the legs and the head, only the red disc is left, and 6,320 pixels change.
- `font:1%a` is 8 characters. `font-size:1%` takes 12: 158 characters, for the same picture.
- The nested `*{` targets body in 2 characters, inside the open rule. Closing the first rule and starting `body{` in its place takes 158 characters, for the same picture.
- `83%` is 332px in 3 characters, like `332`. But the `%` ends the number, so `70` needs no space after it. `margin:332 70-52` takes 155 characters, for the same picture.
- The minus signs need no space before them: `0-2in`, `0-19ch`, `0-53q` and `70-52`. With a space before each one (158 characters), the picture is the same.
- `2in` and `3in` are 192px and 288px in 3 characters. With px everywhere (`0-192px`, `0 288px` twice), the code takes 160 characters, for the same picture.
- `19ch` is 152px on html in 4 characters. With `0-152px`, the code takes 155 characters, for the same picture.
- `188q` and `53q` are 177.64px and 50.08px. Rounded to whole px, `0 178px 0-50px` takes 156 characters, and the head's outline moves: 152 pixels change.
- `#212C` is 5 characters. The opaque `#3E3030` takes 7: 156 characters, and no pixel moves by more than 2.
- A number with no unit in `margin`: `83% 70px -52px` and `-540px 30px 360px` make the code 166 characters, for the same picture.
- Nothing is closed. Closing both rules and the style element with `}}</style>` takes 164 characters, 10 more, for the same picture.
